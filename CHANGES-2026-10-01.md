# Проверенная локальная версия парсера

Проверка выполнена 1 октября 2026 года. Рабочая папка: `C:\Users\Admin\Desktop\events-parser-improved`. Основа: опубликованная ветка GitHub, коммит `60a5e9b`. В этой папке подготовлены изменения кода и данных. Публикация из данной папки на момент составления записки не выполнялась.

Переключатель международных мероприятий теперь требует проведения в России и подтверждения по текущему выпуску: иностранный спикер, выступление на иностранном языке или указанный синхронный перевод. Название "международная выставка", зарубежные экспоненты и участие только русскоязычных стран не дают метку. Для положительного решения сохраняются фрагмент страницы, ссылка и год мероприятия. Вероятная потребность в переводе отделена от прямого упоминания синхронного перевода.

После исправления чтения программ международный фильтр показывает БИОПРОМ 2026, 5–6 октября, Геленджик. Основание: в текущем списке приглашенных спикеров указана Марьям Матар, основатель Ассоциации по борьбе с генетическими заболеваниями ОАЭ. Статус потребности в переводе остается потенциальным. Источник: https://biopromforum.ru/speakers2026. Карточки без подтверждения остаются в общем списке.

**Что изменено**

- Подключен отдельный обработчик афиши TAdviser с наследованием месяца по группе строк. Календарь памятных дат и дней рождения исключен из этого обработчика.
- Подключены актуальные обработчики Conferos, ICT2GO, CNews, ComNews, ICT.Moscow, Crocus и отраслевых источников. Новые прямые источники включают GLOBAL TECH FORUM и отдельные вебинары ПРОТЕЙ. Workevent читается из встроенных структурированных данных, Expomap из Event JSON-LD с сохранением страны проведения.
- Expomap переходит по найденным ссылкам страниц. Лимит задается через `max_pages`, достигнутый лимит явно отражается в отчете. Crocus получает календарь на следующие 12 месяцев без фиксированного года в коде.
- Описания проверяются по названию и году. Для TAdviser при наличии подходящей ссылки проверяется страница самой конференции на Conferos. Краткий текст ограничен 460 символами, HTML и наборы тегов отбрасываются. Текст другой конференции или года не подставляется вместо отсутствующего описания.
- При объединении сохраняются ссылки всех источников. Учтены варианты названий, знаков, городов и ситуация, когда один источник указал только день открытия. Разные даты и разные города не объединяются без дополнительного основания. Неоднозначные совпадения оставлены для проверки в локальном диагностическом файле.
- Исправлены идентификаторы карточек. Они сохраняются при сортировке и загрузке описания. Выявленная коллизия старого идентификатора устранена, JSON и браузерная выгрузка согласованы.
- У Unified Communications Day убрана устаревшая дата 7 октября. Сохранена дата 3 марта 2027 года, указанная на странице конференции.
- Город не извлекается из имен спикеров. Если источники расходятся между онлайн-форматом и городом и подтверждения места нет, место остается неуточненным.
- Исправлены пути локального сервера и экспорта. Публичный GitHub Pages загружает опубликованный снимок, локальный сервер действительно запускает сбор. Ошибка сервера больше не маскируется сообщением об успешном обновлении.

**Файлы для продолжения**

- `scripts/refresh_catalog.py`: общий сбор и проверка страниц.
- `scripts/catalog_core.py`: объединение, короткие описания, международный фильтр, экспорт.
- `scripts/page_facts.py`: сведения со страницы конкретного мероприятия.
- `scripts/source_adapters.py`: отдельные обработчики TAdviser, Expomap, Workevent и новых прямых источников.
- `sources.yaml`: настройки источников.
- `audit/refresh-latest.json`: локальный журнал результатов по источникам.
- `audit/duplicate-review.json`: похожие записи, требующие осторожного сопоставления. Файл сформирован во время проверки, часть совпадений после него уже устранена.

Локальный просмотр: `http://127.0.0.1:8766/`. Обычный запуск через `python serve.py` использует порт 8765. Команды установки и обновления приведены в README.


**Исправление пустого международного фильтра**

Устранены пропуски ссылок с названием вида "Приглашенные спикеры – 2026", чтения карточек Tilda и дат в первом блоке страницы без заголовка H1. Добавлена проверка, что иностранный специалист указан именно среди спикеров, а не спонсоров или экспонентов. Архивные страницы и секции другого года отбрасываются. Кеш, созданный прежней версией правил, больше не блокирует повторную проверку языков.

БИОПРОМ подключен к регулярному сбору с официального сайта. Его варианты названия объединяются в одну карточку. Для приглашенного спикера показана соответствующая оговорка. Проверены положительный пример с ОАЭ и отрицательные примеры со спонсорами, Казахстаном, архивной программой и мероприятием за пределами России.
