# Проверка парсера и расширение охвата

Локальная проверка выполнена 1 октября 2026 года. Каталог вырос с 1 943 до 3 295 событий после объединения совпадений и очистки. Подключено 55 лент с 47 доменов. Из них 4 платформы добавлены впервые: Экспо Афиша, Calendario, KudaBiz и CONFEC. У Expomap подключены общий календарь российских выставок и календарь конференций.

Основание для чисел: начальный снимок в коммите `f5f281c`, текущий `events_upcoming.json`, настройки `sources.yaml`, локальные журналы `audit/refresh-latest.json` и `audit/coverage-verification.json`. Изменения не опубликованы на GitHub Pages.

## Исправленные ошибки

- Обход продолжался некорректно, если последняя страница очереди возвращала ошибку. Теперь найденные ссылки остаются в очереди.
- Ссылки сброса фильтра могли увести Calendario в другой список и создавать повторный обход. Теперь сохраняются исходные условия отбора.
- Вложенные события JSON-LD у Экспо Афиши пропускались. Добавлен разбор `mainEntity`, форматы событий читаются из карточек.
- Дни недели внутри диапазона дат Calendario мешали чтению периода. Добавлена очистка перед разбором.
- Общие календари без определенной темы автоматически попадали в АПК. Теперь они получают категорию `other` и остаются доступны в общей выдаче.
- Названия площадок могли попадать в поле города. Такие значения очищаются, если город не установлен.
- Найденный CSS-код в описаниях отбрасывается. Отсутствующее описание не заменяется выдуманным текстом.
- Длительные события сохраняются с отметкой о необходимости уточнить период.

## Что проверено

Прошли 102 теста Python и 6 сценариев международного фильтра JavaScript. В браузере проверена загрузка каталога и переключатель международных мероприятий. Он показывает 405 событий по согласованным признакам заявленного международного статуса.

Автоматическая проверка всех 3 295 строк подтвердила уникальность идентификаторов, соответствие JSON и браузерной выгрузки, корректный порядок дат, отсутствие прошедших записей и повторных исключений по действующим правилам качества. Описания не превышают 460 символов. Короткое описание есть у 1 996 событий, отметка отдельной проверки страницы описания есть у 195 карточек.

Даты, города и форматы новых обработчиков сверены выборочно с сохраненными HTML-страницами. Каждая карточка вручную не проверялась. Автоматическое объединение не гарантирует отсутствия всех смысловых дублей с разными названиями или расходящимися датами.

Полнота ограничена доступными страницами источников. All-Events и Экспо Афиша отмечены как частично прочитанные. IT-World возвращает страницу проверки браузера и не включен в число работающих источников.
