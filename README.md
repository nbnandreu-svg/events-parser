# Events Parser — календарь мероприятий (IT / АПК / промышленность)

Локальный каталог и UI для агрегации B2B-мероприятий: фильтры по теме, городу, региону, типу; карточка с описанием; выгрузка Excel (.xls); обновление данных.

**Демо (GitHub Pages):** https://nbnandreu-svg.github.io/events-parser/

Код и скрипты: https://github.com/nbnandreu-svg/events-parser

На хостинге открывается готовый снимок каталога. Кнопка «Обновить» и догрузка описаний работают только при локальном `python serve.py`.

## Быстрый старт

```bash
cd events-parser   # или папка репозитория
python serve.py
```

Открой [http://localhost:8765](http://localhost:8765), при необходимости **Ctrl+F5** + «Обновить».

Требования: Python 3.10+. Установите зависимости: `python -m pip install -r requirements.txt`.

## TimePad API (опционально)

Токен **не** хранится в репозитории. Положите его локально:

```bash
mkdir -p ~/.secrets
# значение токена — только у вас, не коммитьте
echo 'YOUR_TOKEN' > ~/.secrets/TIMEPAD_TOKEN
chmod 600 ~/.secrets/TIMEPAD_TOKEN
```

Скрипты читают `/home/box/.secrets/TIMEPAD_TOKEN` или путь из env `TIMEPAD_TOKEN_FILE`.

## Обновление и проверка качества

Основная команда: `python scripts/refresh_catalog.py`. Настройки действующих источников находятся в `sources.yaml`. Сервер `python serve.py` использует тот же сборщик. Для другого локального порта задайте переменную `PARSER_PORT`, например 8766.

- `python scripts/refresh_catalog.py --sources tadviser_calendar conferos --enrich-limit 60` проверяет выбранные источники и страницы мероприятий.
- `python scripts/refresh_catalog.py --offline` очищает и экспортирует уже имеющиеся данные без запросов к сайтам.
- `python -m unittest discover -s tests -q` проверяет даты, источники, описания, объединение и правила международного фильтра.
- `node tests/test_ui.cjs` проверяет синтаксис интерфейса и условия переключателя.

Сбор сохраняет ранее найденные события при ошибке или неполном ответе источника. Истекшие события и подтвержденные дубли убираются из выдачи. Копии исключенных строк доступны локально в `audit/excluded-latest.json`. Отчет по источникам и страницам находится в `audit/refresh-latest.json`. Для Expomap действует ограничение числа страниц, при достижении лимита сохраняется статус `partial_page_limit`. Значение `max_pages` задается в настройках.

Скрипты `ingest_*` сохранены как старые обработчики и вспомогательные библиотеки. Для регулярного обновления используйте общий `refresh_catalog.py`, чтобы сохранить единые правила идентификации и экспорта.

## Международные мероприятия

Переключатель показывает мероприятия в России, для которых есть сведения о выступлении на иностранном языке, синхронном переводе или явное указание иностранного спикера из страны вне русскоязычного списка. Одно слово "международный", иностранные экспоненты, английское название и участие представителей стран СНГ не являются достаточным основанием.

Сведения должны относиться к тому же году мероприятия. В карточке сохраняются фрагмент подтверждения, ссылка и дата проверки. `translation_status=confirmed` означает, что синхронный перевод прямо указан. `potential` означает вероятную потребность по выступлениям или спикерам. Это не подтверждение коммерческого спроса на дополнительного поставщика перевода. При недостатке сведений устанавливается `unknown`, такая карточка остается в общем каталоге.

## Описания и дубли

Короткое описание составляется из текста подходящей страницы мероприятия, обычно занимает до 460 символов и заканчивается на границе предложения. Проверяются название и год. Теги каталога, формы регистрации, чужие события и описания другого выпуска отбрасываются. Если текст не удалось получить, интерфейс сообщает об отсутствии описания.

Совпадения ищутся по названию, дате, месту и проверенным адресам. Разные выпуски с одинаковым названием сохраняются отдельно. У объединенной записи остаются ссылки всех источников. Расхождения в месте и периоде сохраняются для проверки. Идентификаторы карточек не зависят от их номера в отсортированном списке.

## GitHub Pages

Публичная версия показывает готовый снимок. В браузере GitHub Pages нет Python-сборщика. Кнопка "Проверить обновления" загружает последнюю опубликованную выгрузку и не сообщает о новом парсинге сайтов. Новые данные публикуются после локального сбора и проверки файлов `events_upcoming.json` и `events-data.js`.


## Массовая проверка международного фильтра

`python scripts/international_scan.py` проверяет все российские карточки. Журнал `audit/international-coverage.json` позволяет продолжить прерванную работу и различает отсутствие найденной программы, ошибку доступа, несовпадение события/года и прочитанную программу без достаточных сигналов. Скрипт также вызывается общим обновлением каталога.

Проверка учитывает ссылки на организаторов, программы в HTML/PDF и встроенные страницы. Страницы кешируются на 6 часов, повторные обращения к одному адресу объединяются. Флаг `--fresh` сбрасывает использование результатов проверки, но сохраняет кеш скачанных страниц. Новая дата или новый адрес события требуют повторной проверки.
